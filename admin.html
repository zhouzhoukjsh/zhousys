添加产品

产品会按发布时间排到主页：最早的排最前（占大图位），越晚的越靠后。

选 HTML 所在的那个文件夹，里面的图片、CSS、JS 会一起上传， HTML 里的相对路径照常能用。入口优先用 index.html，没有就用最外层的那个 .html。
只传 .html 时，里面的图片需要是外链或直接内嵌在 HTML 里，否则会加载不出来。
链接留空的按钮就是「查看详情」，点了进产品详情页； 填了链接的按钮，点了直接跳去那个地址（比如购买页）。
